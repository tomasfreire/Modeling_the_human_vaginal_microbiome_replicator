# Modeling_the_human_vaginal_microbiome_using_the_replicator_framework
This repository contains code for the results used in the paper:

**Freire, T., Garcia-Romero, M., & Gjini, E. (2026).**  
*Modeling the human vaginal microbiome and its protection against pathogens using the replicator framework for invasion*  
https://doi.org/10.64898/2026.02.20.707042

---

## Repository Contents

### `10_species_cleaned_with_ethnicity_and_community.csv`
Processed vaginal microbiome dataset including Nugent scores, Community State Types (CSTs), and ethnicity annotations.

### `Model_Fitting_and_performance.ipynb`
Python notebook covering model fitting procedures and performance evaluation for Ridge regression and the machine learning models used in the study.

### `Model_validation.ipynb`
Python notebook detailing the validation workflow using synthetic data designed to mimic the characteristics of the data used.

### `Figures.ipynb`
Notebook containing all code used to generate the figures for the main manuscript and Supporting Information (SI).
